# Sabrina Qodri Nova — Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS, and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. An internet connection is needed for the Google Fonts; the site otherwise has no external JavaScript or framework dependencies.

## Publish for free
- **GitHub Pages:** Create a repository, upload `index.html`, then enable Pages from the repository's Settings.
- **Netlify:** Drag the extracted folder into Netlify Drop.
- **Vercel:** Import the repository or deploy the folder as a static site.

## Before publishing
- Confirm the LinkedIn URL and email address.
- Add public project links or screenshots only where you have permission to share them.
- The CV's phone number appears masked, so it has intentionally not been published.
- Project descriptions are based on the supplied CV; no private employer documents or unverified project URLs are included.

## Design notes
Editorial minimalism, warm ivory / charcoal / sage palette, responsive layout, scroll reveal, progress indicator, marquee, hover motion, mobile navigation, and reduced-motion accessibility support.
